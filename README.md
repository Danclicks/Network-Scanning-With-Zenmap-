# Network-Scanning-With-Zenmap-
Scanning IP address and subnet LAN, MAC 

A practical cybersecurity internship exercise focused on network discovery and scanning using Zenmap on Windows.

Tasks performed:

- Installed and configured Zenmap.
- Identified local IP address and LAN subnet.
- Discovered live hosts within the subnet.
- Identified live hosts' IP and MAC addresses.
- Generated and saved network topology in PDF format.

Skills Practised: Network scanning, host discovery, IP and MAC identification, and network mapping.

Purpose: To understand network visibility and identify active devices within a local network.
